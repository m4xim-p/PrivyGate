# Quality Baseline PrivyGate

Текущее качество detection/masking по golden datasets. Обновляется после каждого
изменения детекторов. Источник данных — `tests/data/*.csv`, harness —
`tests/quality_harness.py` и `tests/test_golden_dataset.py`.

Дата фиксации: 2026-09-23.

## Важно: строгий entity/span harness

С 2026-09-22 качество измеряется **строгим entity/span harness**, а не слабой
проверкой `masked != original`. Harness сравнивает итоговые `PIIMatch`
(после штатного overlap resolution) с канонической разметкой ожидаемых сущностей
`(type, start, end, value)` из колонки `expected_entities`.

Правила классификации:

- **TP** — совпали `type`, `start`, `end`;
- **FN** — ожидаемая сущность не найдена;
- **FP** — найдена лишняя сущность;
- **span error** — сущности пересекаются, но границы отличаются;
- **type error** — границы совпадают/пересекаются, но категория неверна;
- **partial leak** — часть ожидаемого PII осталась открытой;
- **overmasking** — замаскированы символы за пределами ожидаемой сущности.

Span/type errors **не** засчитываются как TP, поэтому precision/recall/F1 ниже,
чем давала старая проверка. Это честная картина, а не регрессия детекторов.

## Ключевые проблемы

### Golden dataset
- **BIRTH_PLACE** (span=3, leak=3): детектор захватывает только часть значения
  (например, `г` вместо `г. Новосибирск`), либо исключает служебное слово
  (`городе`), что даёт span error относительно разметки.
- **ADDRESS** (fp=2, span=2, over=2): адреса организаций маскируются; границы
  span неточные.
- **PHONE** (fp=4): горячая линия, служба поддержки, номера заказов маскируются.
- **INN** (fn=1), **PASSPORT** (fn=1): пропуски.
- **EMAIL** (fp=1), **DRIVING_LICENSE** (fp=1), **DATE_OF_BIRTH** (fp=1).

### API dataset (главный пробел)
- **PERSON** (fn=65, span=22, leak=73): имена в сложных предложениях не
  находятся или границы неточные.
- **PASSPORT** (fn=25, span=10, leak=23): формат «серия X номер Y» не
  распознаётся; границы неточные.
- **INN** (fn=13, leak=14): пропуски.
- **CARD** (fn=8, type=4): пропуски и неверная категория.
- **PHONE** (fn=7, span=8, over=8): пропуски и неточные границы.
- **DRIVING_LICENSE** (fn=3), **BIRTH_PLACE** (span=2, leak=2).
- **ADDRESS**: адреса регистрации в сложных предложениях не маскируются.

### Extended dataset
- **PASSPORT** (fp=3): ложные срабатывания.
- **CITIZENSHIP** (span=1, over=1), **PERSON** (type=1).

## Организаторская метрика (приближение)

Организаторы используют кастомную span-based метрику относительно original text
с нормированным расстоянием Левенштейна, FN штрафуется сильнее FP, blanket
masking и захват служебных слов штрафуются. Точная формула и веса не раскрыты.

Приближение в harness (`organizer_approximation`) — это **не** официальный
scorer. Средние значения: golden 0.141, api 0.564, extended 0.224. Эти числа
нельзя сравнивать с целевыми 95% и нельзя выдавать за метрику организаторов.

## Как воспроизвести

```bash
python -m pytest tests/test_golden_dataset.py -q -s
```

## Цель

Строгий harness фиксирует честный baseline. Приоритет — устранение пропусков
(FN) и span/type errors на api dataset, затем снижение ложных срабатываний (FP).
Пороги ratchet поднимаются только после реального улучшения детекторов.
