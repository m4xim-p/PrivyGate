# Дополнительные подтверждения владельца проекта

Дата фиксации: 2026-09-22.

## Профиль нагрузки

Владелец проекта подтвердил по доступной информации: нагрузка подаётся ступенчато,
доходит до 1000 RPS и затем удерживается на этом уровне. Точные значения и длительности
промежуточных ступеней пока не приложены.

Эта запись дополняет сохранённый ответ организаторов о разгоне, среднем RPS около 330
и пиках до 1000. При появлении исходного сообщения организаторов его следует сохранить
отдельным append-only документом и заменить ссылку на эту запись в производных
документах.
